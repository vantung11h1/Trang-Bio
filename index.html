Hướng Dẫn Đưa Lên GitHub Pages

1. Bật chế độ Admin, bấm Xuất Tệp index.html để tải tệp mới nhất.

2. Tải tệp index.html lên kho lưu trữ GitHub của bạn.

3. Vào Settings → Pages, chọn nhánh main hoặc chủ yếu để chạy web miễn phí.

Đã sao chép!
