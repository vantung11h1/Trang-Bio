Đăng Trang Bio Lên GitHub Miễn Phí

Bước 1: Bật nút "Chỉnh Sửa Bio" trên thanh công cụ Admin để điền tên, ảnh đại diện và các link mạng xã hội của riêng bạn.

Bước 2: Nhấn nút màu xanh "Xuất Tệp index.html" để tải tệp index.html (đã lưu cứng dữ liệu mới và tự động khóa chế độ khách) về máy.

Bước 3: Tải tệp index.html này lên kho lưu trữ (Repository) trên GitHub và bật Settings → Pages.

Lưu ý bảo mật: Khách truy cập link GitHub Pages sẽ không thấy nút chỉnh sửa hay nút tải web. Khi cần cập nhật nội dung, bạn chỉ việc bấm biểu tượng ổ khóa mờ ở cuối trang (hoặc nhấn Ctrl + Shift + E) và nhập mật khẩu Admin.
